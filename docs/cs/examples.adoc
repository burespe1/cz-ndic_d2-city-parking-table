Obálka a hlavička::
Kořen `d2:payload` typu `prk:ParkingTablePublication` s atributy `profileName` a `profileVersion`,
`publicationTime` a `publicationCreator`. Odkaz na zdroj dat (`feedType`) je
`x-source:cz-ndic_d2-city-parking-table-pull-v1`.

Parkoviště::
Parkoviště `PR-2` na úrovni 0 (`layer`, `type` = `place`) s názvem a způsobem využití P+R
(`UsageScenario` = `parkAndRide`). Poloha je odkazem na předdefinovanou polohu. Kapacitu, provozovatele, provozní dobu ani souřadnice vzorek neuvádí.
